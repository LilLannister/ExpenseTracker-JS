# 💸 Expense Tracker

Modern ve kullanıcı dostu bir harcama takip uygulaması.  
Kullanıcılar harcamalarını kolayca ekleyebilir, düzenleyebilir, filtreleyebilir ve analiz edebilir.

---

## 🚀 Features

- ➕ Harcama ekleme
- ✏️ Harcama güncelleme
- 🗑️ Harcama silme
- 🔍 Arama (Search)
- 🏷️ Kategori filtreleme
- 🔽 Sıralama (tarih & tutar)
- ⬇️ CSV export
- 🌙 Dark mode
- 💾 LocalStorage ile veri kalıcılığı
- 📱 Responsive tasarım
- ✨ Modern UI/UX (hover effects, empty state, toolbar layout)

---

## 🛠 Tech Stack

- **JavaScript (ES6+)**
- **React**
- **TypeScript**
- **Vite**
- **Bootstrap 5**
- **Custom CSS (Design System & Theming)**
